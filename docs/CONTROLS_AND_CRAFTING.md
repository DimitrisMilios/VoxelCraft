## 1. Keyboard & Mouse Controls

| Key / Input | Mode | Action |
| :--- | :---: | :--- |
| `W` `A` `S` `D` | Gameplay | Move Forward / Strafe Left / Backward / Strafe Right |
| `Shift` (Hold) | Gameplay | Sprint (dynamic field of view boost) |
| `Space` | Gameplay | Jump (or Ascend during Creative Fly Mode) |
| `Ctrl` or `C` | Gameplay | Descend during Creative Fly Mode |
| `F` | Gameplay | Toggle Creative Fly Mode on/off |
| `Mouse Look` | Gameplay | First-person camera look and targeting |
| `Left Click (Hold)` | Gameplay | Mine targeted block (shows 10-stage progressive cracks) |
| `Left Click` | Gameplay | Attack mob / Deal knockback and damage with weapon |
| `Right Click` | Gameplay | Place block / Open Chest, Crafting Table, Furnace, Door, or Bed |
| `1` – `9` / `Scroll Wheel` | Gameplay | Select active Hotbar slot (1 through 9) |
| `E` | Gameplay | Toggle 36-slot Inventory & 2×2 Crafting Grid |
| `Q` | Gameplay | Drop 1 item from active hotbar slot into the world as a 3D pickup |
| `T` | Gameplay | Fast-forward celestial time of day by +2.5 hours |
| `F6` | Gameplay | Quick-save modified chunks and player data to disk |
| `Esc` | Gameplay | Open interactive Pause Menu (Resume, Settings, Save & Quit) |

## 2. Inventory & Container Item Management

When opening the **Player Inventory (`E`)**, a **Crafting Table**, a **Chest**, or a **Furnace**:

* **Left-Click Slot:** Pick up the entire item stack, or place held stack into slot. If slot has matching item, stacks merge up to the maximum stack limit ($64$).
* **Right-Click Slot:** If holding a stack, deposits **1 single item** into that slot (ideal for distributing recipes across the crafting grid).
* **Shift + Left-Click:** Instantly fast-transfers the stack between Hotbar, Backpack, and Chest containers.
* **Drop Outside Window:** Left-clicking outside the GUI bounds drops the held stack onto the ground as a 3D spinning entity.

## 4. Furnace Smelting & Cooking Guide

Place fuel in the bottom slot and items to smelt in the top slot:

| Input Item | Smelting Output | Category |
| :--- | :--- | :--- |
| **Iron Ore** | Iron Ingot | Metallurgy |
| **Gold Ore** | Gold Ingot | Metallurgy |
| **Sand** | Glass | Building Blocks |
| **Cobblestone** | Smooth Stone | Building Blocks |
| **Clay Ball** | Brick | Building Blocks |
| **Raw Porkchop** | Cooked Porkchop (+4 Food) | Food Cooking |
| **Raw Beef** | Steak (+4 Food) | Food Cooking |
| **Potato** | Baked Potato (+3 Food) | Food Cooking |

### 🪵 Fuel Efficiency & Burn Duration
| Fuel Item | Burn Duration | Items Smelted per Unit |
| :--- | :---: | :---: |
| **Lava Bucket** | 1000 seconds | 100 items |
| **Coal / Charcoal** | 80 seconds | 8 items |
| **Wood Log** | 15 seconds | 1.5 items |
| **Wood Planks** | 15 seconds | 1.5 items |
| **Sticks** | 5 seconds | 0.5 items |
